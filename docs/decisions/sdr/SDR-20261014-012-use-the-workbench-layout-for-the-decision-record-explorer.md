# SDR-20261014-012: Use the Workbench layout for the decision-record explorer

## Decision

Adopt variation A, the Workbench layout, as the production explorer's structural direction: a project/filter rail, searchable result list, and persistent record inspector with relationship navigation.

## Why

The persistent three-part layout keeps project scope and filters available alongside the result list while record details and relationships remain visible without replacing the browsing context. The user selected variation A after reviewing the prototype.

## Alternatives considered

- Variation B, Reading room: editorial catalog with a dedicated record-reading pane.
- Variation C, Status board: records grouped into status lanes with a detail drawer.
