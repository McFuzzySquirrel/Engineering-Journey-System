# Changelog

All notable changes to decision-graph are documented here. This project has
not made a decision-graph release yet. The `ejs-final` tag refers to the
previous Engineering Journey System project state, not a decision-graph
version.

This changelog follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- Project documentation describing current status, contribution workflow,
  operational limitations, and planned scope.
- Initial user and administrator guides, an ADR index, and unreleased notes.

### Changed

- Retired the Engineering Journey System from the active repository root and
  preserved it as inactive historical material under `legacy/`.
- Replaced the active project direction with the planned decision-graph tool.

### Not yet shipped

- The decision-graph CLI, record index, MCP integration, and server remain
  unimplemented. See the [implementation plan](docs/IMPLEMENTATION-PLAN.md).
