# Decisions Made
- Decision: Implement semantic payload enforcement using feature-flagged modes (`off|soft|strict`) in hook workflows.
  - Reason: Structural logging alone produced semantically empty sub-agent records (`unknown`, placeholder fields).
  - Impact: Improves traceability and enables quality gating while keeping rollback path.
- Decision: Extend session-end validation to count unresolved semantic sub-agent entries when enforcement is enabled.
  - Reason: Surface incomplete semantic capture at close rather than relying on manual audit later.
  - Impact: Temporary increase in incomplete markers during adoption, followed by better data fidelity.
- Decision: Publish ADR 0019 and README operational guidance in same implementation slice.
  - Reason: Process-level behavior change requires discoverable docs and durable rationale.
  - Impact: Faster onboarding and lower policy drift.
