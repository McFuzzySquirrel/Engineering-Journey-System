# Key Learnings
- GitHub's Copilot platform has three distinct customization mechanisms: Custom Instructions (always-on), Custom Agents (manual selection, persona), and Agent Skills (automatic loading, task-specific)
- Agent Skills are an open standard maintained by Anthropic at agentskills.io, not a GitHub-proprietary concept
- Skills use a `SKILL.md` file with YAML frontmatter (name, description, license) — simpler than agent profiles
- Skills are stored in `.github/skills/<skill-name>/SKILL.md` (project) or `~/.copilot/skills/<skill-name>/SKILL.md` (personal)
- Skills can bundle scripts and resources in their directory — useful for EJS's `adr-db.py` workflows
- The "agent vs skill" question is a false dichotomy — they serve different purposes and are designed to be used together

# If Repeating This Work
Do this: Start with GitHub's Customization Cheat Sheet — it gives the clearest comparison of all mechanisms in one table
Avoid this: Assuming agent and skill are competing concepts — they're complementary
Watch out for: Skills platform support is still in preview for some IDEs (JetBrains, Eclipse, Xcode)
